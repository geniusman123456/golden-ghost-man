# Golden Ghost V35 — Chrome/PWA

Hii ni version ya Chrome/PWA-first. Haitaki EXE kwa Windows na haitaki app store kwa matumizi ya kawaida.

## GitHub
Upload **contents za package hii** moja kwa moja kwenye root ya repository. Root lazima iwe na `public/`, `server.js`, `package.json`, `Dockerfile`, na `railway.json`.

## Railway
Deploy repository hiyo. Weka `SESSION_SECRET` kwenye Variables. Railway itatoa HTTPS domain.

## Install
- Chrome/Edge desktop: fungua HTTPS domain ya Golden Ghost → browser itatoa `Install`/ikoni ya install; pia V35 ina install banner.
- Android Chrome: fungua HTTPS domain → `Install app` / `Add to Home screen`.
- iPhone/iPad Safari: Share → Add to Home Screen.

PWA inahitaji HTTPS kwa matumizi ya kawaida ya service worker/install; Railway public HTTPS domain inafaa.
